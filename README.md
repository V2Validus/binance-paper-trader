# MemePilot — Solana Paper Trader

פרסום ב-GitHub Pages:
1. העלו את `index.html` למאגר GitHub.
2. היכנסו ל-Settings → Pages.
3. בחרו Deploy from a branch, `main`, ו-`/(root)`, ואז Save.

הסימולציה מוגבלת ל-10 פעולות קנייה/מכירה מצטברות. כדי להתחיל מחדש יש לאפס את הסימולציה. אין מסחר אמיתי ואין להזין מפתחות פרטיים או seed phrase.
